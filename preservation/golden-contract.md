# Portable Go golden outcomes

`generate.py --oracle <readonly-oracle> --output <new-directory>` exports actual results by compiling only the harness into a disposable exact `git archive` of oracle `73a93303a9a44cf0a92eaf525331561ed8c04460`. It never imports domain logic from a task branch. The versioned corpus manifest hashes every output and each exporter source file. Run twice into new temporary directories and compare every relative path and hash, including database bytes when present.

The JSON format is UTF-8, plain objects/arrays/strings/numbers/booleans/null; no Go serialization, gob, Rust types or language-specific snapshots are required. Field presence and array order are observable. Rust consumers should replay the language-neutral inputs and compare the expected outcomes. The generator's scenarios and original source/test corpus supplement these representative cases, which do not exhaust every failure/race/platform branch.

- `unicode.json` and `unicode-metadata.json` preserve non-ASCII case folding, composed/decomposed forms, compatibility decomposition, whitespace, combining marks, literal wildcard/backslash, CJK, Arabic and emoji. Data/library Unicode versions are emitted from the producer, not guessed.
- `saved-queries.json` contains v1–v5 defaults/nested queries, recursive retired Broken removal, v5 reused user-tag identity, malformed/duplicate/unknown/unsupported cases, exact canonical payload strings and stable failure categories. `url-queries.json` retains v1–v3 and every existing shared codec case, literal text, canonical sorting/paging, bad versions/fields and current flag rejection. Empty alternatives remain significant.
- `inspection.json` identifies synthetic archive files and complete expected format/UUID/title/description/artwork hashes or stable validation categories. All seven supported format classifications, STUdio disguised as `.pk`, misleading suffix, invalid containers, missing/duplicate/traversal/nested paths, and retained accepted/rejected 7z inputs are present. ZIP bytes come from the baseline deterministic builder; 7z bytes are retained exactly from the original synthetic corpus.
- `imports.json` uses real staging/artwork/catalog/custody adapters for imported, duplicate checksum, different-byte UUID conflict and invalid-container outcomes. Source bytes are rehashed after each inspection/import. No import source is modified.
- `membership-scenario.json` gives explicit ordered identities, titles, flags, queries, retention, exclusions and steps. `collection-union.json` preserves deduplication/overlap and Broken matches. Shelf/member/review files retain unavailable placeholders, source attribution, independent manual retention, explicit Keep/Add, consumed-ticket rejection, ordinary removal/re-addition, explicit exclusion/unexclude and conservative incomplete-source behavior. `SetProtected` is used only to construct historical source-derived storage, not to expose a new UI control.
- `export-plans.json` covers selection/current result/Collection/union/approved Shelf/refined Shelf/unavailable selection/all-ineligible. It retains ordered intended membership, scope identity, ready/skip/conflict reasons, total bytes, formats, overlap, operation-item payloads and blocking state. Broken/unavailable skips reserve no filename or bytes. A real pre-existing destination file exercises no-overwrite preflight.

Only these nondeterministic values are normalized:

1. Nonempty opaque review `token` fields become `<review-ticket>` in observations; ticket reuse/staleness still executes against the real original token and must produce its exact failure category.
2. Known observation timestamp fields `importedAt`, `createdAt`, `updatedAt`, `acceptedAt` and `addedAt` become `2000-01-01T00:00:00Z`. They are not used to hide ordering; seeded IDs/positions are fixed and sort results stay intact. Database generation documents its fixed timestamps separately.
3. The preflight's temporary destination display label becomes `<export-destination>`. Managed paths remain exact relative paths, SHA-256 and original filenames remain unchanged. No arbitrary path replacement occurs.

Seeded story/Collection/Shelf/source IDs, UUIDs, candidate/member order, origin associations, warning/outcome codes, flags, query structure/canonical strings, eligibility, counts, bytes and file contents are never normalized. An unexpected error aborts generation; it cannot become a generic successful fixture. Intentional decoder hardening requires retaining the old input/outcome with a separately reviewed exception; this corpus grants no such exception.

Generation does not construct a network client or read production settings. Go dependency retrieval may use the developer's configured module proxy; it is unrelated to product network behavior. Generation uses explicit temporary synthetic roots and no normal profile. A fixture containing a foreign/placeholder absolute recovery path must be cloned and identity-verified/rebound before any recovery replay.
