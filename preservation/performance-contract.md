# Limits and performance preservation

`preservation-manifest.json` freezes the actual archive, operation, database, query, review, HTTP, history/log and presentation bounds with exact source references. Numeric budgets remain acceptance gates; the manifest does not relax them. The current-host observations in `performance-observation.json` are evidence of an actual Go run, not a cross-machine timing promise or a Rust pass.

`corpus/limits/` executes boundary−1, boundary and boundary+1 through actual frozen Go APIs. Archive header accounting covers path bytes/depth, entry counts, expanded bytes and aggregate ratio without allocating gigabytes; it intentionally exercises the Budget primitive rather than constructing a real duplicate-entry archive. Bounded metadata/artwork reads use documented repeated-byte recipes, exact returned lengths and hashes. Query cases preserve actual rune/page/group failures. Full container/duplicate/CRC/unknown-size/overflow/cancellation behavior remains covered by the frozen complete inspection tests and portable archive inputs; primitive headers alone do not qualify an archive decoder.

`corpus/performance/stories.jsonl` is a language-neutral 5,000-row fixture produced by the existing deterministic `performancefixture.Generate`, with exact UUIDs, titles, original deterministic import chronology, normalized titles, flags, validation state, embedded artwork path, language and age metadata. `distribution.json` records all six Collection IDs, validation/language/tag counts, the 64-title cycle, and 24 actual procedural 320×400 PNGs retained at their relative paths. These are record-only archive rows; no usable story/archive payload is implied. Fields not exported include incidental current-time metadata row creation timestamps; original seeded import times are retained for sorting.

`review5000.json` runs the separate retained Shelf workload: 5,000 UUIDs, 1,000 Broken flags, an all-matching source plus an overlapping 2,500-story Moon source. It preserves every deduplicated candidate's order, identity, flag and source IDs, 50 explicit Add decisions, the resulting approved count and 4,950 remaining proposals. This freezes both distribution and actual membership outcomes; it is not merely a proposed benchmark size.

Retain warmed p95 ceilings for query100ms, literal search120ms, combined filters150ms, six Collection counts250ms, deep page120ms, and 24 full local PNG loads/decodes50ms. Retain UI1,000-story completion≤3,000ms and input dispatch p95≤100ms; 5-second ceilings apply independently to complete 5,000-story Shelf preview and recomputation+50-add apply. Review/create/warning/detach/exclusion decisions remain bounded to25 rows; linked deletion presents one affected Shelf at a time. The 300-candidate browser accessibility fixture remains a retained source test.

Frame/timer50ms thresholds are scheduler diagnostics. Record host suspension separately from product input delays. Query-plan strings in producer observations are engine-specific diagnostics, not portable byte-for-byte Rust expectations: preserve indexed archive/language/tag lookup obligations and equivalent work using the retained plan tests and semantic outcomes. Do not normalize away query/order/count/eligibility differences.

The real ARM baseline measurements use Go1.26.5 on macOS15.7.7, Apple M4 Pro/Mac16,8,12 logical CPUs and48GiB RAM;20 warmed backend samples, five browser samples, four Shelf preview samples and50 additions. Original timing observations remain retained separately in `docs/performance/`. No production data/network is used.

Native startup, idleCPU, peakRSS/decoded cache, package size, four-host renderer/software performance and accessibility remain section2/16 qualification outputs. No values are invented here, no Intel/Linux/Windows host is qualified, and no old-runtime retirement is authorized.
